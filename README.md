## An experimental FreeTableTop game in Javascript & Node.js (2024)

The idea was to try to implement a multiplayer web game where every player could do free moves live.
I think though the all architecture would have to be rethinked in order for this to work. 
The project is currently unscalable and I will thus just archive it as unfinished work.

## Run
```bash
node server.js
```

and go into `http://localhost:8888/` in your browser
